# DESIGN.md — wxread 控制台设计规范（G1 基线）

> 版本 v1.0 · 2026-11-23 · 定稿色板：**A 钢蓝 #2563EB**
> 本文是实现的唯一视觉依据。任何页面不得引入本文之外的色值、字号、圆角。
> 参考样张：`mock/variant-steel.html`（桌面 `mock/final-A-1280.png`、移动 `mock/final-A-390.png`）
> 令牌代码：`mock/tokens.css`（实现时落到 `docs/design/tokens.css`，为唯一定义处）

---

## 1. 设计立场

三句话概括，用来判断"这算不算跑偏"：

1. **工具，不是产品页。** 用户每天只看两个问题：今天读完没有、哪个账户坏了。页面上除这两件事以外的东西都该更弱。
2. **颜色只在需要眼睛跳过去的地方出现。** 主色 + 浅阶 + 警示色 + 失败色，四类封顶；整页彩色面积 ≤ 8%。
3. **数字优先于装饰。** 数字等宽对齐、单位小一号、趋势用柱不用曲线。不用渐变、不用大阴影、不用插画。

|---|---|---|

| `--surface` | `#FFFFFF` | 卡片、表格底 |
| `--surface-2` | `#F2F4F7` | 表头、次级区块、文字按钮 hover |
| `--border` | `#E4E7EC` | 卡片描边、分隔线 |

| 令牌 | 值 | 用途 | 约束 |
|---|---|---|---|
| `--accent` | `#2563EB` | 主按钮底、今日数字、"当前页"下划线、满额柱 | 白字对比 5.17:1 ✔ |
| `--accent-hover` | `#1D4ED8` | 主按钮 hover / active | — |

| `--accent-text` | `#1D4ED8` | 浅底上的主色文字（如"运行中 45%"） | 在 `--accent-weak` 上对比 ≥ 4.5:1 ✔ |

### 2.3 语义色（只用于状态，不用于装饰）

| 令牌 | 值 | 底 | 用途 |
|---|---|---|---|
| `--ok-text` / `--ok-bg` | `#067647` / `#ECFDF3` | 正常、成功 | |
| `--warn-text` / `--warn-bg` | `#B54708` / `#FFFAF3` | 需重新绑定、未满额提醒、告警条 |
| `--warn-border` | `#FEDF89` | 告警条描边 | |
| `--danger-text` / `--danger-bg` | `#B42318` / `#FEF3F2` | 登录失败、已停止 | |
| `--danger-solid` | `#D92D20` | 危险实心按钮（仅在确认框内） | |

**硬规则**

- 主色不用于表达"成功"，成功一律走 `--ok-*`。否则"今天读完了"和"按钮"会混淆。
- 同一屏最多出现 **1 个**主色实心按钮。
- 状态色只允许出现在徽章、告警条、表格里的结果列；不得作为卡片底色大面积铺开。

## 3. 字体与排版

```
--font: "Inter", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
--mono: "SF Mono", "JetBrains Mono", ui-monospace, monospace;
```

| 令牌 | 字号/行高 | 用途 |
|---|---|---|
| `--fs-display` | 28/34 · 600 | 页面标题 |
| `--fs-metric` | 30/36 · 620 · `tabular-nums` | 指标卡大数字 |
| `--fs-h2` | 15/22 · 600 | 卡片标题 |
| `--fs-body` | 13/20 · 400 | 正文、表格 |
| `--fs-sm` | 12/18 · 400 | 表头、次级说明 |
| `--fs-xs` | 11/16 · 500 | 图例、柱标签、脚注 |

- **所有数字**（指标、表格数值、时间、分钟数）必须 `font-variant-numeric: tabular-nums`，否则刷新时会左右抖动。
- 单位（分钟/个/%/天）用 `--fs-sm` + `--text-3`，紧贴数字右侧、基线对齐。
- 中文不设 `letter-spacing`；英文/数字标签 `letter-spacing: .01em`。
- 不使用斜体；不使用字重 700 以上（Inter 700 在小字号发黑）。

## 4. 间距、圆角、层级

| 令牌 | 值 | 用途 |
|---|---|---|
| `--sp-1..8` | 4 / 8 / 12 / 16 / 24 / 32 / 40 / 56 | 唯一间距刻度，禁止 10px、14px 这类随手值 |
| `--r-sm` | 6px | 徽章、小按钮 |
| `--r-md` | 10px | 输入框、按钮 |
| `--r-lg` | 14px | 卡片 |
| `--r-full` | 999px | 头像、圆点 |
| `--shadow-1` | `0 1px 2px rgba(16,24,40,.04)` | 卡片唯一阴影 |
| `--shadow-2` | `0 8px 24px rgba(16,24,40,.10)` | 浮层、下拉、Toast |

- 卡片间距 16，卡片内边距 16（移动端 12）。
- 分段之间用 `--sp-6`(24) 留白，**不画横线分隔**；只有表格内部用 1px `--border`。
- 层级只有 3 层：底（`--bg`）→ 面（`--surface` + 描边 + `--shadow-1`）→ 浮层（`--shadow-2`）。

## 5. 组件清单（只允许这 12 个）

每个组件必须实现下表全部状态才算完成，缺状态在 G2 清单里直接打回。

| # | 组件 | 必做状态 |
|---|---|---|
| 1 | AppBar | 默认 / 滚动吸顶 / 连接异常（圆点变琥珀 + 文案"连接中断，重试中"） |
| 2 | 指标卡 | 默认 / 加载（骨架条）/ 空（"—"）/ 告警描边 |
| 3 | 账户行 | 默认 / hover / 运行中（进度）/ 需重绑 / 已停止 / 选中 |
| 4 | 状态徽章 | ok / warn / danger / running / neutral 五型，不可自造第六型 |
| 5 | 进度条 | 确定进度 / 不确定（条纹动画）/ 完成 |
| 6 | 表格（运行记录） | 默认 / 空 / 加载 / 行 hover / 截断（最近 100 条的说明） |
| 7 | 柱状图 | 有数据 / 单日缺数据（灰柱 + tooltip"无记录"）/ 空 |
| 8 | 按钮 | primary / secondary / ghost / danger-solid / disabled / loading（宽度锁定，不许因 loading 变形） |
| 9 | 输入框 | 默认 / focus（`--border-strong` + 2px `--accent-weak` 外环）/ 错误 / disabled |
| 10 | 告警条 | warn / danger / 可关闭 |
| 11 | Toast | success / error / 3 秒自动消失，不遮挡主按钮 |
| 12 | 空状态 | 无账户 / 无记录 / 无网络，各配一句下一步动作 |

**连接状态圆点**：连得上 = `--ok-*`；30 秒无心跳 = `--warn-*`；超过 2 分钟 = `--danger-*`。**不许恒绿**（旧版 bug）。

## 6. 图表规则（数据对比的地基）

1. 只允许 **柱状图 + 横向进度条**。不用折线（日粒度数据点太少，折线会制造假的连续性）、不用饼图、不用双 Y 轴。
2. 柱宽 ≥ 14px，圆角 4px 上圆下方，柱间距 ≥ 8px。
3. **柱顶标数值**（`--fs-xs`、`--text-3`）：读者不该靠估高读数据。
4. Y 轴不画刻度线标签，只画 3 条 `--chart-grid` 网格线；最大值取"目标值的整数倍"，保证 40 分永远贴顶。
5. 缺数据（没跑或没记录）用 `#EDF0F4` 空心柱表示，**不能用 0 高的柱**——0 表示"跑了但没读"，两者含义不同。
6. 颜色只用两类：满额 `--chart-1`、未满 `--chart-2`；第三类状态用琥珀色描边，不允许再加第四种填充色。
7. 图例必须在图下方常驻（"满额 40 分 / 未满额"），不依赖 hover。
8. 单位写在图表卡副标题（"单位：分钟 · 按账户累加"），不在每个柱上重复。

## 7. 无障碍与可读性（硬性）

- 正文对比度 ≥ 4.5:1，**最小字号 11px 且颜色不得浅于 `--text-3`**（旧版 9px + `#98A2B3` 是明确违规）。
- 图形元素（柱、进度条）与背景对比 ≥ 3:1。
- 焦点可见：`:focus-visible` 必须有 2px `--accent` 外环 + 2px offset，不许 `outline:none`。
- 所有图标按钮必须有 `aria-label`；状态徽章用文字而非纯色表达（色盲可用）。
- 刷新数据时只替换变动节点，**不许整页 innerHTML 重建**（会丢焦点与滚动位置）；数字更新用 `aria-live="polite"` 包住数字本身，不包整页。
- 动画：进度条 1.2s 循环；其余过渡 ≤ 160ms；尊重 `prefers-reduced-motion`。
- 触控目标 ≥ 40×40px，移动端行内按钮不叠放。

## 8. 版式与响应式

- 内容最大宽 1180px，两侧留白 ≥ 24px。
- 桌面：`[账户表 1fr] [右栏 320px]`，右栏放"计划"和"近 7 日"。
- `≤ 820px`：右栏落到表格下方；表格每行转成 2 行卡片（第一行账户+状态，第二行 今日/目标 + 操作），**不允许横向滚动**。
- `≤ 480px`：指标卡 2×2 网格；标题 24px；按钮全宽。
- 移动端首屏必须能看到"今日阅读"和"哪个账户异常"。

---

## 9. 文案规范

- 说结果，不说过程：`20 / 20 分` 而不是 `已成功同步阅读进度`。
- 说下一步，不说错误码：`登录态已失效（连续 2 次失败），重新扫码后会自动恢复每日运行` 而不是 `-2012`。
- 时间用相对 + 绝对：`今天 01:09`、`3 天前`、`11-11`。
- 不用感叹号，不用"请""您"，不用 emoji。
